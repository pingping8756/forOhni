## 🔥 五大荒謬排班模式
1. **【共體時艱模式】（院方狂推預設）**
   - 只要操不死，就往死裡操！
   - 無情花花班輪迴（白班 D ➔ 大夜 N ➔ 小夜 E ➔ 花花班），所有預休假單自動駁回並強制轉為「積假」。
2. **【學姐優先封建模式】**
   - 封建階級制度的極致體現。
   - 阿長與資深前輩固定白班＋週末爽休；菜鳥小白連續 14 天包大夜＋輪值死亡交叉（大夜下班8小時直接接白班）。
3. **【媽祖聖筊指示模式】**
   - 把命運交給神明，班表比心電圖跳得還亂，連擲十個笑筊隨機定生死。
4. **【極度健康幸福模式】（彩蛋報錯）**
   - 妄想每週雙休、絕無花花班、大夜後補休48小時？
   - 系統將直接彈出 **`ERROR 404: HEALTH_NOT_FOUND`**，判定為非法妄想並強制修正為共體時艱模式！
5. **【全員逃走大烙跑模式】**
   - 老娘不幹了！全員班表全數填滿「886 (離職)」，全員轉行去手搖飲店搖五十嵐。

## ✨ 趣味功能與護理地獄梗
- **即時崩潰指標統計**：全院離職意願、剩餘可用肝功能、全科累積肝指數（9999+ U/L）、學姐白眼次數統計、每日黑咖啡消耗量。
- **一鍵抽換班別**：點擊排班表任意格子，隨時替同事手動換班（D/E/N/OFF/花/積/886）。
- **一鍵正式離職信產生器**：包含血手印、經典離職理由（「我阿公在大夜班托夢給我」、「肝指數高到可當日光燈管發光」），支援一鍵標記離職並重整班表。
- **阿長的靈魂拷問 PUA 語錄**：「大家互相幫忙一下嘛，下次換妳放假！（永遠沒有下次）」
- **全體餵食高單位 B 群**：緊急注射高劑量維他命B群，撫平同仁心靈 2 秒鐘。
- **自訂名冊管理**：可以自由新增/刪除人員，把真實好友或同事的名字放進去一起體驗花花班地獄（支援 LocalStorage 本地儲存）。
- **匯出與列印**：支援一鍵複製純文字班表（方便直接貼到 LINE 護理同仁群組）及列印 A4 排班總表。
